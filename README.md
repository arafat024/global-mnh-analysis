# Global MNH Analysis

This repository showcases a comprehensive analysis of global Maternal and Newborn Health (MNH) metrics using tools like Power BI, DAX, and Python. Each analysis focuses on specific indicators and trends, providing actionable insights.

## Current Analyses
1. **[ANC1_Coverage_README.md]**:
   - Explores global trends in Antenatal Care (ANC1) coverage from 2000–2022.
   - Key insights include country and regional comparisons, trends by income groups, and more.

2. **Future Analyses**:
   - Maternal mortality trends.
   - Infant care patterns.
