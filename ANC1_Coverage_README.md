# ANC1 Coverage: Patterns and Progress (2000–2022)

This project analyzes global ANC1 (Antenatal Care, at least has first visit) coverage trends using Power BI. It explores coverage variations across countries, regions, and income groups, offering actionable insights into global health.

## Key Features
- **Interactive Dashboard**:
  - Global average ANC1 coverage trends from 2000–2022.
  - Regional and country-level comparisons.
  - Highlights of countries with the highest and lowest coverage.
- **Data Cleaning**:
  - Raw data from [UNICEF](https://data.unicef.org/resources/resource-type/datasets/) processed using Power Query.
  - Exported cleaned data for reproducibility.

## Insights
- **Global Trends**: ANC1 coverage has improved significantly over the years.
- **Lowest Coverage**: Afghanistan reports consistently low coverage.
- **Regional Insights**: South Asia shows gradual improvement but remains below global averages.
